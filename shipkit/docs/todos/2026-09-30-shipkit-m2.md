## 目标

从“agent 已装好、token 手工抄写”推进到“受控安装 + 短期配对 + 仓库推拉实测 + 状态恢复”的首次接入闭环：

1. **UX05 受控安装与升级**：install.sh 幂等升级（保留既有凭据/角色/端口）、产物 sha256 校验、失败回滚（.old 保留至健康检查通过）、版本戳。
2. **UX06 短期配对**：agent 侧一次性配对码（哈希存储、有效期、次数限制、原子消费、重放拒绝）；CLI `ship pair` 经 HTTPS 入口交换长期 token（哈希存储、角色受限）；loopback 例外仅用于本机测试。
3. **UX07 仓库凭证与推拉检查**：凭证按角色经 agent API 分发（0600 文件、不重启、不落日志）；builder 实测推送、runtime 实测拉取（FROM scratch 测试镜像，写入范围先展示，测试对象留档不自动删除）；三级结果（地址可达/认证成功/推拉实测）。
4. **UX08 状态恢复**：resume 基于实际状态——token 已可用则跳过配对；配对码一次性由 agent 端保证；wizard 断点续跑不重复消费。

## 边界

- 不创建/销毁云资源、不动生产、不真实 GC、不新增 SSH 控制通道、不公开发布。
- TLS 实机（公网域名+证书）与真实远端仓库验收缺环境 → 本地等价验证（loopback http 例外 + 自签 CA HTTPS + registry:2 容器 + Debian 容器测 install.sh），缺口如实记录。
- 兼容：现有明文 token 配置继续可用；tokenRef 为新增可选，二者互斥（config 校验）。
