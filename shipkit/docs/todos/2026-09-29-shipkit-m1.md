## 目标

用户安装后直接使用 `ship`，并通过 `ship init` 为"已有 Dockerfile 的单应用 + 已安装 agent 的固定机器"完成配置，无需手写 YAML。init 默认只完成配置，不触发部署。

## 边界（不动）

- 不公开发布安装包（仅本地版本化 tarball）；不改生产服务器；不建/销毁云资源；不真实 GC；不新增 SSH 通道。
- M1 沿用现有 agent 长期 token 认证；短期配对/受控安装是 M2。
- 不覆盖用户 Dockerfile、环境变量文件；不 git add/clean/revert 用户工作区。
