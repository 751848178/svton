- 客户端故障时序与真实身份写入 13/13；消费与心跳重试复用原请求，心跳单个在途，只有匹配回执才推进序号。新进程使用新 bootId，凭据失效不自动重新登记。
- 可信网关独立单测 12/12；真实 TLS → 标准生产 Next → 编译 Nest → 新迁移 SQLite 11/11。默认机器入口未设置时关闭，人类会话和机器凭据互不授权，边缘证明与内部 API 证明分开。

## 后续门槛

生产 TLS 边缘须在注入自身私密证明前拒绝原始重复请求头。标准 Next/Node 已丢弃的原始头不能由 App Route 重新观察；本轮使用实际 TLS 边缘夹具验证，没有将默认 NPM 配置冒充此证明。

完整注册台账和凭据被复制到另一物理主机后，仅靠本模块不能在原租约过期时识别物理克隆；替换机器仍需受控认领。文件测试证明进程终止恢复，没有声称断电证明。

反向任务通道、项目身份绑定、安装/资源页面、生产登记、维护交接及 Agent 自升级仍待 B–E 分模块验收。旧冻结标签不移动，不提前开放执行就绪或用原始 Agent Job 代替平台自发布任务。
