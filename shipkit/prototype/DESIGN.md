# 发布面板视觉与交互

模式：Operate。用户已确认项目列表→项目详情→按步骤发布，沿用仓库工作台的克制表格、侧栏、清晰文字与一致控件。

全局导航参考 TWGG：固定 256px 浅灰侧栏，顶部品牌与菜单搜索，分组菜单，36px菜单行，浅灰选中背景和2px左侧竖线，底部本机控制端卡片。项目内展示名称与服务器IP；桌面内容独立滚动，内距32px。手机隐藏侧栏，以44px菜单按钮打开280px原生dialog抽屉，支持关闭/遮罩/Escape与焦点恢复，手机内容内距20px。TWGG原实现没有手机抽屉，这部分按Shipkit适配。

项目列表以可点击的项目名称进入详情，运行端统一显示服务器 IP 与名称；服务技术名称和中文名称都可以在新标签页打开对应入口。
发布过程恢复为选择服务、核对计划、执行发布、查看结果四步；选择范围在表格，影响在计划清单。仅外层步骤条采用 Devpilot 的箭头分段样式，保持 Shipkit 的绿色。步骤名称使用原生按钮，可点击与键盘切换；门槛未满足时禁用并解释原因。
标题左侧返回确定的父页面，使用TWGG的20px左箭头与8px标题间距，无边框、底色或圆角按钮外观；悬停只变绿色，键盘焦点保留。手机保留44px透明触控区域并将箭头对齐内容起点。生成计划放在选择服务区域顶部，开始/再次发布放在执行内容顶部，资源处理在构建机状态中，历史与新发布放在结果说明附近；页面底部不再承担步骤导航。
执行页连续显示创建构建机、构建镜像、推送镜像、部署服务、健康检查、释放构建机六项过程。进入时只准备计划，手动开始；完成只更新状态，由用户点击外层步骤条查看结果，或再次开始。运行中锁定导航和开始，待释放资源先处理再开新轮。手机将标题与动作在同一区域换行，保持阅读和焦点顺序。
细节在右侧日志抽屉查看，顶部展示步骤、状态与服务范围，正文只展示当前步骤日志，未执行有明确空态。下拉采用有焦点环、选中状态和键盘支持的组件浮层；保持原型已有的绿白视觉。
浅色使用场景为日常本机操作。白色主表、偏暖中性背景、深色文字、绿色情况/主要动作、琥珀色部分结果、红色失败。
系统中文字体与熟悉的 sans UI 字体；等宽仅用于版本、命令与时间。无宣传性大标题、指标卡或装饰图。
手机折叠为项目列表→详情→分步服务列表/计划/结果；所有主要操作与范围信息可见。

按用户要求，所有页面上的原型提示已移除，按钮使用发布/回滚/释放。模型原始事件保留，显示层统一清理受控日志文案。
发布、回滚和资源释放仍为模拟操作，不产生云或服务器修改，输入不接收真实凭据。TWGG 服务链接打开实际网站，网站项目的服务链接打开本机服务页。此边界保留在文档和交付说明中。
