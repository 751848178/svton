# F383 + F384 Integration

## Goal

Integrate the complete F383 and F384 history onto the latest local `master`,
resolve every divergence by source-backed semantics, and produce enough
database, API, web, browser, and data-readback evidence to decide whether the
result is safe to merge into `master`.

- In scope: Git ancestry and divergence, semantic merge resolution, migration
  compatibility, F383/F384 regressions, Picshare runtime readback, evidence
  reporting, and progress-index synchronization.
- Out of scope: F385, resource providers, resource requests, unrelated
  refactors, private-remote credential sign-off, pushing, and merging into
  `master`.
- Protected unrelated files in the original checkout: `check2.mjs` and
  `docs/todos/2026-07-29-agent-session-isolation.md`.
