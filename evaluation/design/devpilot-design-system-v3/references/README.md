## Devpilot translation rule

Borrow interaction principles, not visual skins:

- From Linear/Vercel: density, hierarchy, compact navigation, precise state and revision reading.
- From Railway: project/environment spatial context and contextual diagnosis.
- From Lovable/Replit/v0: task-first language, visible progress and progressive technical detail.
- Reject: generic card dashboards, chat as the whole product, black-and-white cloning, purple AI gradients, floating glass, fake automation, and hidden production governance.
