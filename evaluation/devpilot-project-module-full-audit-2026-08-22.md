## 三、横切问题模式与系统性解决方案

66 个问题不是 66 个孤立 bug，它们聚成 8 个系统性模式。按模式治理比逐条修更省成本：

### 模式 1：死按钮——enabled 但点击零反馈（5+ 处，P1 最集中类别）
涉及：SET-1（版本查看详情）、SET-2（查看变更）、SET-4（技术证据菜单项）、DOM-3（预览配置）、DOM-4（删除）。
- 共同特征：按钮 enabled、无 loading、无 toast、无导航、控制台疑似错误被吞。
- 方案：① 统一排查这几个 handler 的事件绑定与 try/catch 吞错；② 建立前端规约——任何按钮点击后必须有可感知反馈（导航/弹层/toast/disabled 之一），做不到就 disabled 并给原因；③ 在 E2E 里加「每个按钮点击后 DOM 必须发生变化」的冒烟断言。

### 模式 2：危险操作无确认、写操作无反馈
涉及：INFO-1（验证并更新凭据点击即写）、INFO-8（刷新无反馈）、staging「部署」单击即重部署、DEP-1 同族。
- 方案：写操作三分法落地到组件库——破坏性操作必须二次确认；写操作必须 loading + 结果 toast；只读刷新至少给 spinner。设计稿 `mockups/04-resource-binding.html` 的确认范式可复用。

### 模式 3：raw ID / 枚举值直接上屏（贯穿所有区域）
涉及：INFO-3（面包屑项目 ID）、INFO-5/6、REL-2、ROD-4/6、DEP-6/8、SET-9/10、DOM-9 等十余处。
- 方案：建立统一的 display-name 映射层（releaseOrder→名称+短号、BuildRun→#N、环境→中文名、枚举→文案表），技术 ID 一律折叠进「技术证据」区。符合 workbench 契约「技术 ID 折叠」原则。设计稿 `03-release-list-gates.html` 已示范发布域的做法。

### 模式 4：状态/计数不自洽（可信度杀手）
涉及：ROD-1（阻断 3/5/0）、ROD-3（前置条件已满足 vs 尚未满足）、DEP-2、DEP-4、DEP-9（46 vs 30）、INFO-2（518/100/20）、INFO-11（backend 张冠李戴）、SET-13（0 修订谈当前修订）。
- 方案：计数与状态单源化——门禁计数由同一个 selector 派生三处展示；环境状态由一个状态机输出，禁止各面板各自拼接文案。设计稿 `03-release-list-gates.html` 的门禁单一事实源方案直接适用。

### 模式 5：URL/query 状态生命周期缺陷
涉及：WIZ-2（`create=true` 残留）、REL-1（筛选不进 URL、`stageId`/`releasePlanId` 深链被忽略）、DOM-8（`?new=true` SPA 内点击不触发）、DEP-3（runId 聚焦无退出）、EV-1（失效 view 静默回退）。
- 方案：制定 query 参数规约：谁在什么时机写入/清除；关闭弹窗必须清理对应 query；不认识的参数显式提示或 302 纠正而非静默忽略；每个深链状态必须有可见的退出出口。

### 模式 6：表单校验缺失或形态不一致
涉及：WIZ-1（校验错误地阻断一切）、WIZ-4（只有禁用无提示）、DOM-1（域名无格式校验）、DOM-2（空提交零反馈）、SET-3/SET-16（禁用/启用无原因）。
- 方案：统一表单规范——inline 错误文案 + 禁用按钮必须带原因（tooltip 或旁注）；格式类字段（域名、版本号、KEY）前后端同规则校验；pattern 属性改由 JS 校验函数实现并配单测（WIZ-1 这类 JSX 转义 bug 可被单测直接拦截）。

### 模式 7：响应式 1280px 硬伤
涉及：SET-14（版本表格列重叠，历史未修）、REL-3（操作列裁切）、ROD-11（步骤名截断）、DOM-10（弹窗按钮裁出视区）、DEP-10（长文本断词）。
- 方案：表格在 <1440px 切换为「主列 + 更多」折叠形态；长 token 用 truncate+title 替代 break-all；弹窗内容区滚动而底部操作栏固定。设计稿 `02-version-management.html` 的表格折叠方案适用。

### 模式 8：无障碍与语义缺失
涉及：ROD-10（div 当 toggle 键盘不可达）、DOM-5（弹窗无 role=dialog）、INFO-9（tooltip 只在 aria-label）。
- 方案：交互元素一律 button/a 语义；弹窗统一走组件库 Dialog；信息展示与 aria 解耦（可视 tooltip + aria 双写）。
